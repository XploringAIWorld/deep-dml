# Security Policy

## Supported Versions

Only the latest release of Deep-DML receives active security updates and bug fixes:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.0   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Deep-DML seriously. If you discover a security issue or vulnerability, please follow responsible disclosure practices:

1. **GitHub Private Vulnerability Reporting**:
   Please use GitHub's private vulnerability reporting feature on the repository's Security tab to submit confidential reports directly to project maintainers.

2. **Repository Issues / Discussions**:
   If private vulnerability reporting is unavailable, please open a security advisory draft via GitHub or contact the maintainers directly through their verified GitHub profile channels.

Please **do not** report security vulnerabilities via public GitHub issues, pull requests, or public discussion boards until the issue has been addressed and patched.

## Response Process

- We will acknowledge receipt of your vulnerability report within 72 hours.
- We will provide an assessment of the issue and collaborate on a remediation strategy.
- Upon releasing a fix, an advisory will be published acknowledging the reporter (unless anonymity is requested).
